# Proyecto

Este repositorio tiene dos cosas:
- **AutoClips** (raíz): programa que saca clips de directos y vídeos. Ver README.md.
- **Miniaturero** (`miniaturero/`): diseño de miniaturas de YouTube y pósters deportivos hecho por Claude en la conversación.

Si el usuario pide una miniatura, un póster o cambios en uno, **lee primero `miniaturero/CLAUDE.md`** y sigue ese rol, flujo y normas.
