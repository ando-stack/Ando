# Arcade del Recreo

Web de minijuegos para clase. Es un único archivo (`index.html`): ábrelo con doble clic o súbelo a cualquier hosting estático (GitHub Pages, Netlify…). No necesita servidor ni instalación.

## Modos
- **Modo Historia**: 8 capítulos («La biblioteca del aula 404»). Cada uno es un juego con objetivo; ganas de 1 a 3 estrellas y el final cambia según las estrellas.
- **Modo Libre**: los 8 juegos desbloqueados, en fácil, normal o difícil, con récords.
- **Reto del día**: un juego distinto cada día con premio de monedas.
- **Duelo por equipos**: para proyectar en la pizarra. Preguntas aleatorias y marcador (teclas A / L, espacio = nueva pregunta, R = respuesta).

## Juegos
Cálculo Relámpago · Letras Revueltas · Parejas · Diana Veloz · Serpiente Glotona · Trivia Express · Eco de Colores · Salva el Globo

## Guardado
Todo se guarda en el navegador (localStorage): varios perfiles por ordenador, nivel y XP, monedas, avatares comprados, 18 logros, récords y progreso de la historia.
En **Perfil → Copia de seguridad** se puede copiar un código y pegarlo otro día (u otro ordenador) para recuperar la partida.
