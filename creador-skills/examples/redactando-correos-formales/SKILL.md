# Redacción de correos formales

## Objetivo

Producir correos profesionales en español claros, breves y correctos, listos para enviar.

## Cuándo usarla

- Escribir un correo nuevo a un cliente, proveedor, administración o superior.
- Responder a un correo recibido manteniendo un tono profesional.
- Revisar o «pulir» un borrador del usuario.

No la uses para mensajes informales (WhatsApp, chats con amigos), cartas de
presentación de empleo extensas ni textos de marketing.

## Pasos

1. Identifica: destinatario, relación (cliente, superior, desconocido), objetivo del
   correo y acción que se espera del destinatario.
2. Si falta el objetivo o el destinatario, pregunta solo eso. Para todo lo demás, usa los
   valores por defecto de la sección Reglas.
3. Redacta siguiendo el formato de salida.
4. Revisa con la lista de comprobación y entrega.

## Reglas

- **Tratamiento:** «usted» por defecto; «tú» solo si el usuario lo indica o el borrador ya tutea.
- **Asunto:** máximo 8 palabras, concreto e informativo («Presupuesto reforma cocina – revisión»).
- **Saludo:** «Estimado/a + nombre:» si se conoce; «Buenos días:» si no. Tras el saludo, dos puntos, nunca coma.
- **Primer párrafo:** el motivo del correo en una o dos frases. Nada de «Espero que se encuentre bien» salvo que el usuario lo pida.
- **Cuerpo:** párrafos de 2–4 frases; una idea por párrafo. Fechas, importes y plazos explícitos.
- **Petición:** la acción esperada, con plazo si lo hay, en un párrafo propio.
- **Cierre:** «Un saludo,» o «Atentamente,» (este último para administraciones o primeros contactos) + firma.
- **Longitud:** menos de 150 palabras salvo que el contenido lo exija.
- Nunca inventes datos (fechas, importes, nombres): deja un marcador `[FECHA]`, `[IMPORTE]` y avísalo.
- Al pulir un borrador, conserva los datos y la intención; cambia solo forma y estructura.

## Formato de salida

```
**Asunto:** …

Estimado/a …:

[Motivo]

[Detalle]

[Petición y plazo]

Un saludo,
[Firma]
```

Si se pulió un borrador, añade después una lista breve «Cambios principales» (máximo 3 puntos).

## Lista de comprobación antes de entregar

- [ ] El asunto resume el correo.
- [ ] El motivo aparece en las dos primeras frases.
- [ ] La acción esperada y el plazo están claros.
- [ ] Sin datos inventados; marcadores señalados.
- [ ] Tratamiento coherente en todo el texto.

## Casos límite

- **Tema delicado** (reclamación, retraso, mala noticia): reconoce el problema en la
  primera frase, ofrece una solución concreta y evita culpar.
- **El usuario pide otro idioma:** aplica las mismas reglas en ese idioma.
- **Borrador muy largo:** propón una versión reducida y menciona qué se ha eliminado.

## Ejemplo

**Entrada:** «Escribe a Laura García, clienta, que el pedido 4512 llegará con una semana de retraso por falta de stock.»

**Salida:**
```
**Asunto:** Retraso en su pedido 4512

Estimada Laura:

Le escribimos para informarle de que su pedido 4512 llegará con una semana de retraso por una rotura de stock de nuestro proveedor.

La nueva fecha estimada de entrega es el [FECHA]. Lamentamos las molestias que esto pueda causarle.

Si prefiere cancelar el pedido o sustituir el artículo, responda a este correo y lo gestionaremos de inmediato.

Un saludo,
[Firma]
```
Nota: falta la nueva fecha de entrega; se ha dejado el marcador [FECHA].
