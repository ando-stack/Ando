# Motion graphic de Pereira7 (Remotion)

Vídeo horizontal 1920x1080, 30 fps, 19 s, con estética de noche de boxeo (negro, rojo y dorado).

Escenas: intro con el nick, presentación con el cinturón, "Streamer / Luchador / Showman", collage de fotos y cierre con "Síguelo en directo".

```bash
npm install
npm run studio   # editar y previsualizar
npm run render   # genera out/pereira7.mp4
```

- Textos, colores y duraciones: `src/Pereira7.tsx` (constantes arriba del archivo).
- Fotos: `public/` (`cutN.png` son las fotos con el fondo recortado).
